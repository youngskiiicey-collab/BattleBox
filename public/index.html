Install Android App Locally

This project compiles directly to an installable Android .apk using Gradle (Kotlin DSL) and also builds automatically via GitHub Actions.

  • From AI Studio: Open the settings menu → Generate APK / AAB or Download ZIP.
  • From GitHub Actions: Download the battle-box-debug-apk artifact from the latest workflow run.
  • From Local Terminal: Run gradle :app:assembleDebug and install via adb install -r app/build/outputs/apk/debug/app-debug.apk.
